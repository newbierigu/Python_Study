## 상대 경로?

- 현재 작업 디렉토리를 기준으로 파일/디렉토리의 위치를 나타내는 경로
- 상대 경로는`.` 기준으로 계산
  - `.` = 현재 디렉토리
  - `..` = 상위 디렉토리
  - `..`/디렉토리명 = 한 단계 위로 올라간 뒤 그 디렉토리로 이동
  - `.`/파일명 = 현재 디렉토리 내 특정 파일

### 현재 위치가 `B` 이고 `user/A/B` 상태일 때

- `cd ..` 입력 시 `A` 디렉토리로 이동
- `A` 디렉토리 내 `codeit.txt` 이란 파일의 내용 확인 시
  - `cat ../codeit.txt`

## Git에서 `branch`는?

- 일단 Git이라는 플랫폼 자체에 대한 이해를 해보면 `branch` 이해가 쉬음
- Git은 개발자들의 협업 공간
- 이 협업 공간에서 다양한 작업을 하다보면, 충돌은 피할 수 없음
- `branch`는 한 프로젝트 내에서 안전하게 협업을 진행하기 위해 `main`(기본 축 코드)와 분리된,
- 작업 공간을 제공하는 역할
- 그 외 여러가지 장점 존재

### `branch`의 장점

- 여러 개발자들이 동시에 작업해도 충돌을 줄일 수 있음
- 기존 만들어논 기본 축 코드(`main` or `master`)은 유지하며 새로운 기능 추가 및 Test 진행 가능
- 특정 버전을 유지하고 패치하기 수월해짐
