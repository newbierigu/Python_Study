# 데이터의 생김새

---

## 고차원(`High-Dimensional`) 데이터와 클러스터링 문제\

- 정의: **`Feature`(`변수)가 수십~수백 개 이상인 데이터**
- 문제: 차원이 늘어나면 거리 계산이 무의미해지고(**`차원의 저주`**), 클러스터링이 불안정해짐

<br>

### 문제점과 해결 방법

#### 문제점

    - 거리 집중 현상: 모든 점 간 거리가 비슷해짐
    - 스케일 불균형: 큰 단위 변수 하나가 전체 거리를 지배
    - 계산 비용: 차원이 커질수록 연산량 급증

<br>

#### 해결 방법

    - 전처리: 표준화(Scaling), 저분산 변수 제거
    - 차원 축소: PCA, TruncatedSVD (→ 수백 차원 → 수십 차원)
    - 거리 선택: 텍스트는 코사인, 범주형은 자카드 등
    - 대용량 대응: MiniBatchKMeans, FAISS 같은 근사 최근접 탐색

<br>

### 실무 사용 팁

- **클러스터링 전처리 파이프라인을 만들어두면 실험 반복이 쉬움**
- 실제 분석용 클러스터링은 보통 PCA → KMeans/HDBSCAN 조합 많이 사용
- 시각화는 UMAP/t-SNE로 2D로 내려서 확인

## 주성분 분석(`PCA`) vs 요인 분석(FA) 차이

### 직관적 비유

- **PCA = “사진 줄이기”**  
   → 큰 사진 파일을 픽셀 손실 없이 압축하는 느낌.
  데이터의 분산(정보량)을 가장 잘 유지하는 새로운 좌표축(주성분)을 찾아 차원을 줄임.

<br>

- **FA = “숨은 성격 찾기”**  
  → 여러 질문지(설문 응답)에서 **공통된 성격 요인(내향성, 외향성 등)**을 추출하는 느낌.
  단순 압축이 아니라, **변수들 사이 숨어있는 요인(잠재 변수)**을 해석하려는 목적.

<br>

### 목적 차이

    - PCA: 데이터 요약/압축 → 예측 모델 성능 개선, 계산량 감소
    - FA: 데이터 구조 해석 → “무엇이 공통적으로 영향을 주는가?” 설명

<br>

### 결과 해석 차이

- **PCA 결과**
  “데이터의 분산을 가장 잘 설명하는 축은 무엇인가?”
  → ex) 고객 행동 데이터를 PCA하면, “결제 패턴 + 이용 빈도”라는 축이 나옴.
  해석보다는 차원 축소·시각화·전처리에 유용.

<br>

- **FA 결과**
  “이 변수들을 묶는 공통된 요인은 무엇인가?”
  → ex) 심리 설문 20문항을 FA하면, “자존감 요인, 외향성 요인”처럼 잠재 요인이 도출됨.
  해석·의미 부여에 강함.

<br>

### 실무에서의 활용

PCA

- 이미지 압축, 텍스트 임베딩 차원 축소
- 머신러닝 피처 전처리 (100차원 → 20차원)
- 대규모 데이터 시각화

<br>

FA

- 심리학/교육학 설문 분석 (잠재 요인 추출)
- 고객 세분화 요인 찾기 (“브랜드 충성도”, “가격 민감도” 등)
- 마케팅 리서치에서 설문항목 축약

## 히스토그램의 주요 단점과 대안 시각화

### 단점

    - 빈 폭(bin size) 선택에 따라 모양 달라짐
    - 세부 구조(꼬리, 작은 피크) 왜곡
    - 그룹 비교가 직관적이지 않음

<br>

### 대안 시각화

      - KDE(커널 밀도 추정): 연속적 분포 곡선
      - ECDF: 누적 분포로 그룹 비교 용이
      - Box/Violin plot: 중심+분산+왜도 한눈에
      - Hexbin / 2D KDE: 2차원 분포 표현

---

## 마무리 요약

- **고차원 클러스터링**: 피처 선택·차원 축소·적절한 거리 지표가 핵심
- **PCA vs FA**: PCA는 압축, FA는 잠재 요인 해석 → 목적에 따라 선택
- **히스토그램 한계 극복**: KDE, ECDF, Box/Violin 등 상황 맞는 대안 활용
