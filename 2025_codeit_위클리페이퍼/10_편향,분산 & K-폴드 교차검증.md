# 편향 & 분산, K-폴드 교차 검증

---

## 1. 편향(Bias)과 분산(Variance)

### 1-1. 정의

- **편향(Bias)**

  - 모델이 **지나치게 단순**해서 생기는 **일관된 오차**
  - 훈련·검증 둘 다 성능이 **골고루 낮음** (언더피팅)

- **분산(Variance)**

  - 모델이 **지나치게 복잡**해서 **데이터의 잡음까지 외움**
  - 훈련 성능은 좋지만 검증 성능이 **요동침** (오버피팅)

- (참고) **비감소 잡음(Irreducible Noise)**
  - 데이터 자체의 우연성/측정오차 → 어떤 모델도 완전히 없앨 수 없음

### 1-2. 관계(편향–분산 트레이드오프)

- 모델 복잡도 ↑ ⇒ **편향 ↓, 분산 ↑**
- 모델 복잡도 ↓ ⇒ **편향 ↑, 분산 ↓**
- 직관: 너무 단순하면 **일관되게 틀림(고편향)**, 너무 복잡하면 **데이터마다 말 바꿈(고분산)**
- (회귀, 제곱손실 기준 직관식)  
  **예측오차 ≈ 편향² + 분산 + 잡음**

### 1-3. 증상과 처방

| 상황(증상)                              | 추정 문제 | 처방 아이디어                                                                            |
| --------------------------------------- | --------- | ---------------------------------------------------------------------------------------- |
| 훈련 점수 **낮음**, 검증 점수 **낮음**  | 고편향    | 모델 복잡도 ↑ (특성 추가, 비선형/트리), 규제 약화(L2↓/L1↓), 학습 더 진행                 |
| 훈련 점수 **높음**, 검증 점수 **낮음**  | 고분산    | 규제 강화(L2/L1↑), 모델 단순화, **더 많은 데이터**, 교차검증/앙상블(배깅), **얼리 스탑** |
| 데이터 자체가 **시끄러움**(재현 어려움) | 잡음      | 더 좋은 피처/센서, 이상치 처리, 데이터 정제, 불확실성 보고                               |

### 1-4. 실무 체크리스트

- **정규화/규제**: 규제 강하면 편향↑·분산↓, 약하면 편향↓·분산↑
- **데이터량**: 샘플 많아질수록 분산↓
- **교차검증**: 분산을 추정·통제하는 기본 도구
- **앙상블**: 배깅(Random Forest) → 분산↓ / 부스팅 → 편향↓(때로 분산↑)
- **전처리**: 누수 방지(스케일링/인코딩/오버샘플링)

## 2. K-폴드 교차 검증

### 2-1. 정의

- 데이터를 K개로 나눠 **K번** 학습/평가
- 매번 **K−1개 폴드로 학습**, **남은 1개 폴드로 평가**, K개의 점수를 평균
- 분류는 보통 **계층화(Stratified K-Fold)** 로 클래스 비율 유지

### 2-2. 왜 쓰나?

1. **일회성 홀드아웃보다 안정적** (평가의 요동 ↓)
2. **데이터를 더 효율적으로 사용** (훈련 데이터 비율↑)
3. **하이퍼파라미터 튜닝**의 표준 절차
4. 데이터 누수 점검(폴드 기준으로 전처리·특징 생성 분리)

### 2-3. K 값 선택 가이드

- **K가 클수록**:
  - 장점: 훈련에 쓰는 데이터 비율↑ ⇒ **편향 낮은** 성능 추정
  - 단점: **분산이 커질 수 있음**(폴드 간 편차↑), **계산량↑**
- **K가 작을수록**:
  - 장점: 계산 가벼움, 분산 상대적으로 안정
  - 단점: 훈련 데이터 적어져 **편향↑**

| 데이터/상황                    | 추천 K              | 이유/비고                             |
| ------------------------------ | ------------------- | ------------------------------------- |
| 일반적인 분류/회귀             | **5 또는 10**       | 업계 관행, 안정성·비용 균형           |
| 데이터 매우 적음               | **10**              | 훈련량 확보(편향↓)                    |
| 계산 비용 빡빡함               | **5**               | 속도·안정 균형                        |
| 매우 큰 데이터                 | **3~5**             | 이미 표본 충분, 빠른 반복             |
| 타임시리즈(누적/순차)          | **TimeSeriesSplit** | 미래 정보 누수 방지(일반 K-Fold 금지) |
| 클래스 불균형                  | **Stratified**      | 각 폴드의 비율 유지                   |
| 동일 개인/상품 중복 샘플 존재  | **GroupKFold**      | 그룹 단위로 분리(누수 방지)           |
| 모델/파라미터 선택의 편향 제거 | **Nested CV**       | 바깥 폴드(평가) + 안쪽 폴드(튜닝)     |

### 2-4. 실무 팁(누수·재현·불균형)

- **스케일링/인코딩/피처선택/SMOTE** 등은 **각 훈련 폴드 안에서만** 수행
- `shuffle=True, random_state=고정`으로 **재현성** 확보
- 불균형 분류는 **StratifiedKFold** 기본, 필요 시 **평가지표**(F1/AUPRC) 조정
- **Repeated K-Fold**: 분산 더 낮추고 싶을 때(비용↑)
- **Nested CV**: 파라미터 탐색 편향 제거(연구/보고서에 적합)

### 2-5. 이해 포인트

- K 선택은 **편향–분산–계산비용의 균형 맞추기**
- 무조건 K를 키우기보다 **데이터 구조(시간, 그룹), 문제 난이도, 리소스**를 함께 고려

---

## 3. 요약(한 장 정리)

- **편향**: 단순한 모델이 **일관되게 틀림** → 언더피팅
- **분산**: 복잡한 모델이 **데이터마다 흔들림** → 오버피팅
- **트레이드오프**: 복잡도/규제/데이터량으로 균형 맞추기
- **K-폴드**: 성능을 **안정적으로 추정**하고 **튜닝**에 필수
  - 보통 **K=5 또는 10**, 상황 따라 Stratified/Group/TimeSeriesSplit 선택
  - 전처리·리샘플링은 **폴드 안에서만**(누수 금지)
